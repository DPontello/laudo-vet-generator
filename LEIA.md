# Laudo Vet Generator — Como usar

Guia rápido para gerar os laudos de ultrassonografia no seu computador.
**Não precisa instalar nada** e **não precisa de internet** para usar.

---

## 📥 Primeira vez (só uma vez)

1. **Salve** o arquivo `.zip` que você recebeu numa pasta fácil de achar.
2. Clique com o **botão direito** nele → **"Extrair tudo…"** → confirme.
   Sugestão: extraia para `C:\laudo-vet`.
3. Abra a pasta extraída. Dentro dela existe um arquivo chamado **`iniciar.bat`**.

> 💡 **Dica:** clique com o botão direito em `iniciar.bat` →
> **"Enviar para" → "Área de trabalho (criar atalho)"**.
> Assim você abre o sistema direto pela área de trabalho nas próximas vezes.

---

## ▶️ Abrir o sistema (toda vez que for usar)

1. Dê **duplo-clique** em **`iniciar.bat`**.
2. **Só na primeira vez**, o Windows pode mostrar um aviso azul
   *"O Windows protegeu o seu computador"*. É normal (acontece com todo
   programa novo). Clique em **"Mais informações"** → **"Executar assim mesmo"**.
3. Vai abrir uma **janela preta** — **não feche essa janela!**
   Ela é o "motor" do sistema e precisa ficar aberta enquanto você usa.
4. Em poucos segundos o **navegador abre sozinho** no formulário do laudo.
   Se não abrir, digite na barra de endereço do navegador: **`localhost:8080`**

---

## ✍️ Fazer um laudo

1. Preencha o **cabeçalho** (paciente, espécie, responsável, veterinário
   requisitante, data, etc.).
2. Preencha cada **órgão**. Para agilizar, use o botão **"Tudo Normal"**:
   ele preenche as descrições padrão de órgãos saudáveis — depois é só
   ajustar o que estiver alterado.
3. Se quiser anexar **imagens** do exame, use o campo de imagens
   (aceita arquivos **JPEG**).
4. Antes de finalizar, você pode clicar em **"Prévia editável"** para ler e
   ajustar o texto do laudo.
5. Clique em **"Gerar PDF"** (ou, dentro da prévia, **"Gerar PDF do texto
   editado"**). O **PDF do laudo** é gerado com o timbrado e seus dados —
   é só conferir, salvar e imprimir.

---

## ⏹️ Fechar

Quando terminar, **feche a janela preta** (ou pressione `Ctrl + C` nela).
Isso desliga o sistema.
Fechar apenas o navegador **não** desliga.

---

## ✅ Bom saber

- **Não precisa de internet** para usar.
- Os **checklists personalizados** que você criar (botão **"⚙ Checklists"**)
  ficam **salvos** no seu computador para as próximas vezes.
- Você pode alternar entre **tema claro e escuro** no botão **"☀ Claro"**.

---

## ❓ Se aparecer um erro

Se ao abrir a janela preta aparecer uma mensagem em vermelho começando com
**`[ERRO]`**, o próprio sistema explica o que faltou.

👉 **Tire uma foto da tela e envie para o suporte técnico.**
